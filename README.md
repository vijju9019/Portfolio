## 📌 Overview

This repository hosts the official personal portfolio website for **Vijay Purandare** — an **AI/ML Engineer, Software Developer, and AI Builder** based in Bangalore, India. 

Designed with a high-contrast, modern product aesthetic inspired by curated portfolio systems, this web application merges fluid physics-based micro-interactions, dark/light ambient theming, client-side routing, and real-time GitHub integration to showcase production-grade projects and architectural case studies.

---

## ✨ Key Features

### 🌓 Dual-Theme Design Engine
- **Light Theme**: Warm cream canvas (`#faf8f5`) paired with deep charcoal typography (`#1c1917`) and vibrant accents.
- **Dark Theme**: Deep carbon slate (`#0c0d10`) with glowing glassmorphism and balanced contrast.
- Persistent theme selection using `localStorage` with smooth zero-flash script bootstrapping.

### 💻 Interactive AI Engineer Workspace
- Simulated live desktop device mockup featuring:
  - **Docker Workspace Runtime** (`CloudBase-IDE.tsx`)
  - **On-Device NPU Neural Execution** (`MindDesk-NPU.py`)
  - **Autonomous Security Digital Twin** (`CyberWar-Twin.ts`)
- Interactive tab switching, live console output, and real-time latency indicators.

### 📄 Interactive Multi-Mode Resume (`/resume`)
- **ATS Paper View**: Pixel-accurate print layout matching the official 1-page resume with standard serif typography, structured sections, and print styles (`@media print`).
- **Modern Cards View**: Bento-grid cards categorized by technical competencies, work experience timeline, and hackathons.
- **Embedded PDF Viewer**: Inline `<object>` preview with full-screen access to the genuine 123 KB resume PDF.
- 1-click **Download PDF**, **Print**, and **Copy Markdown** formatted text.

### 🔬 In-Depth Project Case Studies (`/projects/:slug`)
- Architectural breakdowns with:
  - Problem statements & solution blueprints
  - Interactive System Architecture flowcharts
  - Technical decisions & rationale tables
  - Engineering challenges overcome & quantifiable results
  - Direct links to GitHub repositories & live demos

### 🗺️ "My AI / ML Journey" Roadmap Tracker
- 17-step progressive milestones tracking Python foundations, NumPy/Pandas, Scikit-learn, Model Evaluation, Hyperparameter Tuning, MLOps, Deep Learning, and Generative AI.
- Visual state filters: **Completed**, **In Progress**, and **Upcoming**.

### ⌨️ Command Palette (`Ctrl + K` / `⌘ + K`)
- Keyboard-first command palette for instant navigation across sections, direct project jumping, external links, and resume actions.

### 🌐 Live GitHub Activity (`@vijju9019`)
- Real-time GitHub REST API integration displaying live public repositories with star counts, language tags, and commit timestamps.

## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version `v18.0.0` or higher recommended)
- `npm`, `yarn`, or `pnpm`

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vijju9019/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173`.

4. **Build for production**:
   ```bash
   npm run build
   ```
   The compiled bundle will be output to the `dist/` directory.

5. **Preview production build**:
   ```bash
   npm run preview
   ```

## 🚀 Deployment

### Option A: Vercel (Recommended)
This repository includes [`vercel.json`](./vercel.json) for client-side routing.
1. Connect your GitHub repository at [vercel.com](https://vercel.com).
2. Framework Preset will auto-detect **Vite**.
3. Click **Deploy**.

### Option B: GitHub Pages
An automated GitHub Actions workflow is included at [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml).
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment > Source**, select **GitHub Actions**.
3. Push to `main` branch to trigger auto-deployment.

### Option C: Netlify
The [`public/_redirects`](./public/_redirects) file is pre-configured.
- Either import via Git or drag-and-drop the `dist/` folder directly to [app.netlify.com/drop](https://app.netlify.com/drop).
